Fernosa Gelato Theme (v1.0.0)

INSTALL
1) Upload the ZIP in WordPress > Appearance > Themes > Add New > Upload.
2) Activate theme.
3) Install/activate WooCommerce.
4) Create product categories with these slugs (optional but recommended):
   - special-coffee
   - dessert-gelato
   - cold-drinks
5) Create pages:
   - About (use template "درباره ما (Fernosa)")
   - Contact (use template "تماس با ما (Fernosa)")
6) Set a static front page:
   Settings > Reading > Your homepage displays > A static page (Homepage: Home)

CUSTOMIZE
Appearance > Customize:
- Colors: primary/gold
- Home hero: title, description, background image
